# Сегментные лендинги TutorOnline

Три лендинга под холодный трафик Avito, Wildberries и Ozon с квиз-формой брони бесплатного пробного урока: 1–4, 5–9 и 10–11 класс.

**Превью вёрстки:** https://vsevolodyakushev.github.io/tutoronline-segment-landings/

Превью статическое: вёрстка, квиз, таймер скидки и счётчик мест работают, а отправка заявки — нет, за неё отвечает Node-сервер. Полная версия поднимается локально.

## Запуск

```sh
cd landings
npm install
npm run build
npm start          # http://127.0.0.1:8765/5-9/
```

Нужен Node.js 22 или новее. Подробности, параметры контента и чек-лист запуска — в [landings/README.md](landings/README.md), размещение на сервере — в [landings/SERVER_SETUP.md](landings/SERVER_SETUP.md).
