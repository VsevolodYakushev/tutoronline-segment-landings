# Лендинги TutorOnline под ключевые слова маркетплейсов

Один лендинг с квиз-формой брони бесплатного пробного урока, который подстраивается под ключевое слово объявления. Первый сегмент адреса выбирает направление: заголовок первого экрана и предвыбранные класс с предметом совпадают с тем, что человек искал, и их можно сменить.

19 направлений по трём кластерам аудитории (1–4, 5–9, 10–11 класс) под 38 ключевых слов, отобранных маркетингом. Сборка разворачивает один шаблон в 22 страницы — 19 направлений и 3 кластерных для прямого трафика; вручную страницы не дублируются.

```
/ege-matematika/   Бесплатный пробный урок с репетитором по подготовке к ЕГЭ по математике   → 11 класс, математика
/oge-geometriya/   Бесплатный пробный урок с репетитором по геометрии                      → 9 класс, геометрия
/5-9/              кластерная страница без направления
```

**Превью вёрстки:** https://vsevolodyakushev.github.io/tutoronline-segment-landings/

Превью статическое: вёрстка, квиз, таймер скидки и счётчик мест работают, а отправка заявки — нет, за неё отвечает Node-сервер. Полная версия поднимается локально.

## Запуск

```sh
cd landings
npm install
npm run build
npm start          # http://127.0.0.1:8765/oge-geometriya/
npm test           # 89 unit- и серверных тестов
```

Нужен Node.js 22 или новее. Подробности, параметры контента и чек-лист запуска — в [landings/README.md](landings/README.md), размещение на сервере — в [landings/SERVER_SETUP.md](landings/SERVER_SETUP.md).

Ссылки для рекламного кабинета: `npm run ads:links -- --origin https://<домен>` собирает `ads-links.csv` — ключевое слово, ёмкость, направление и готовый адрес с метками.
