# Contract: раскладка брони в вебхук `SaveRegistrationRequest`

**Endpoint**: `https://profile.tutoronline.ru/DataService.svc/SaveRegistrationRequest` (переопределяется `LEAD_WEBHOOK_URL`)
**Формат**: `application/x-www-form-urlencoded` (по умолчанию) или JSON (`LEAD_WEBHOOK_FORMAT=json`), как в базовом лендинге
**Связано**: [lead-api.md](lead-api.md)

Вебхук принимает ровно шесть полей. Новых полей не добавляем: всё, что требует FR-023, кладём в `info` структурированной строкой, которую менеджер читает глазами, а CRM при необходимости разбирает по `|`.

| Поле вебхука | Значение | Пример |
|--------------|----------|--------|
| `name` | `name` из формы | `Мария` |
| `phone` | `phone` из формы | `+7 (912) 345-67-89` |
| `email` | `email` из формы или пусто | `maria@example.com` |
| `subject` | `math` → `Математика`, `russian` → `Русский язык` | `Математика` |
| `landing` | URL сегмента + 5 стандартных UTM | `https://example.ru/5-9/?utm_source=avito&utm_content=4128837712` |
| `info` | Структурированная строка (ниже) | — |

## Формат `info`

```text
Бронь пробного урока TO-7KQ2MD | Сегмент: 5-9 | Класс: 7 | Предмет: Математика | Репетитор: Роман Юрьевич | Слот: чт 12.11.2026 18:00 МСК | Промокод: <PROMO> (100%) | Скидка −1500 ₽: запрошена | Вариант: a | Источник: avito | Объявление: 4128837712 | Реклама: нет | Обязательство прийти: да
```

Правила:
- Порядок пар фиксирован, разделитель — ` | `, внутри пары — `: `.
- Отсутствующие значения: `—` (например, `Объявление: —` при визите без `utm_content`).
- Для `placeholder`-репетитора: `Репетитор: подобрать (русский язык)`.
- Длина `info` ≤ 1000 символов, значения обрезаются до 120 символов каждое.

## Подтверждение

Без изменений относительно базового `isConfirmed`: успех — только явный `ok`/`true`/`success: true`/`SaveRegistrationRequestResult` с успехом. Пустой HTTP 200 или HTML — `upstream_unconfirmed`.

## Проверка перед запуском

Одна помеченная тестовая заявка на каждый сегмент (`name` = `ТЕСТ лендинг <seg>`) с разрешённым номером. В CRM проверяются все шесть полей и читаемость `info`. Пока это не сделано, критерий приёмки ТЗ «все события и UTM приходят в CRM» считается невыполненным.
