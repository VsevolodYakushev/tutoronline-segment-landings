# Contract: адреса страниц и параметры URL

**Владелец**: `landings/server.mjs`, `landings/build.mjs`
**Потребители**: объявления Avito, Wildberries и Ozon; QA

## Страницы

| Путь | Сегмент | Ответ |
|------|---------|-------|
| `/1-4/` | 1–4 класс | `dist/1-4/index.html` + `Set-Cookie: tst_v1_1-4=…` при отсутствии |
| `/5-9/` | 5–9 класс | `dist/5-9/index.html` + `Set-Cookie: tst_v1_5-9=…` |
| `/10-11/` | 10–11 класс | `dist/10-11/index.html` + `Set-Cookie: tst_v1_10-11=…` |
| `/` | — | `302 → /5-9/` с сохранением query |
| `/assets/…`, `/css/…`, `/js/…` | общие | Белый список расширений, `Cache-Control: public, max-age=31536000, immutable` для файлов с хэшем в имени |
| `/api/lead` | — | [lead-api.md](lead-api.md) |

Путь без завершающего слеша (`/5-9`) получает `301` на `/5-9/`. Всё прочее — `404` JSON, как в базовом сервере.

## Параметры запроса

| Параметр | Значения | Действие |
|----------|----------|----------|
| `utm_source` | `avito` \| `wb` \| `ozon` \| иное | Записывается в `firstTouch`, если записи ещё нет |
| `utm_medium`, `utm_campaign`, `utm_term` | строка ≤ 300 | То же |
| `utm_content` | ID объявления, строка ≤ 300 | То же; в CRM — «Объявление» |
| `grade` | Целое в диапазоне сегмента | Предвыбор класса на шаге 1; без параметра или вне диапазона — `Segment.defaultGrade` |
| `subject` | `math` \| `russian` | Предвыбор предмета (по умолчанию `math`) |
| `tutor` | `Tutor.id` | Предвыбор репетитора на шаге 2, если он ведёт выбранный предмет |
| `v` | `a` \| `b` | QA-переопределение варианта, не сохраняется |

## Шаблон ссылки для объявлений

```text
https://<домен>/<сегмент>/?utm_source=<avito|wb|ozon>&utm_medium=cpc&utm_campaign=trial-<сегмент>&utm_content=<ID объявления>
```
